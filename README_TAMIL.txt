உங்களுக்கு செய்ய வேண்டியது:
1. data/MAX_STORE_Google_Sheet_Template.xlsx-ஐ Google Drive-ல் Google Sheets ஆக மாற்றவும்.
2. அந்த Sheet → Extensions → Apps Script.
3. backend/Code.gs-ஐ முழுவதும் paste செய்யவும்.
4. setup() ஒருமுறை Run செய்யவும்.
5. Deploy → New deployment → Web app → Execute as Me → Anyone.
6. கிடைக்கும் /exec URL-ஐ js/app.js-ல் PASTE_YOUR... இடத்தில் paste செய்யவும்.
7. இந்த முழு folder-ஐ Vercel-ல் deploy செய்யவும்.
